nvc

The simulator nvc.wasm is nvc, the VHDL compiler and simulator by Nick Gasson and contributors (development version 1.24, commit 75da1dd), compiled to WebAssembly with the WASI SDK 25 and run with its JIT interpreter (no LLVM). The VHDL-2008 libraries in vhdl-lib.bin (std, ieee and nvc) were compiled by this same build. nvc is free software under the GNU General Public License, version 3 or later; the IEEE library sources carry their own licence notices.

  • Original source: github.com/nickg/nvc
  • Changes made for the browser build: nvc-wasm.patch (32-bit pointers in the JIT, no dlopen, no memory protection) and nvc-wasi-support.tar.gz (compatibility headers, stubs for functions WASI lacks, and the table of built-in functions used instead of dlopen)
  • Full licence text: GNU GPL v3
