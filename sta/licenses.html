Source and licences

The STA and Constraints Labs run entirely in your browser. Your files are not uploaded anywhere.

OpenSTA

sta.wasm is OpenSTA by Parallax Software and contributors, compiled to WebAssembly with the WASI SDK 30. OpenSTA is free software under the GNU General Public License, version 3.

  • Source: github.com/parallaxsw/OpenSTA, commit 05b6001
  • Change for the browser build: opensta-wasm.patch (turns off link-time optimisation so C++ exceptions keep working in WebAssembly)
  • Licence: GNU GPL v3

Linked into sta.wasm

  • Tcl 8.6.16: Tcl licence. Built without threads, sockets or subprocesses; the missing system calls are replaced by stubs that fail cleanly: wasi_stubs.c, pwd.h, grp.h, netdb.h, sys/wait.h, termios.h.
  • CUDD BDD package: BSD-3-Clause
  • zlib 1.3.1: zlib licence
  • LLVM libc++, libc++abi and libunwind 21.1.4, rebuilt with WebAssembly exception handling: Apache-2.0 with LLVM exception
  • Eigen 3 (header-only): MPL-2.0

Cell libraries and example data

  • sky130hd_tt.lib.gz, the GCD netlist and SPEF: from the SkyWater SKY130 PDK and OpenROAD flow, Apache-2.0. Copies taken from the OpenSTA examples.
  • asap7_small_ss.lib.gz, asap7_small_ff.lib.gz, reg1_asap7.spef: subset of the ASAP7 predictive PDK by Arizona State University, BSD-3-Clause (the licence text is inside each library file).

STA workshop labs

  • Lab scripts, netlists, constraints and slides: © vlsideepdive (Vikas Sachdeva). Free to use for learning; the slides PDF may not be modified or redistributed.
  • sky130_fd_sc_hd__tt_025C_1v80.lib, sky130_fd_sc_hd__ss_100C_1v60.lib, sky130_fd_sc_hd__ff_n40C_1v95.lib: SkyWater SKY130 HD standard cells, from the SkyWater PDK and the FOSSi Foundation ciel releases, Apache-2.0. Stored gzip-compressed.
  • s27_Early.lib, s27_Late.lib (and the copies s27_min.lib, s27_max.lib): early/late libraries for the ISCAS s27 benchmark from the TAU 2015 timing contest, used for education.
  • ibex_top.v: the lowRISC ibex RISC-V core (Apache-2.0), converted with sv2v and synthesised to Sky130 HD with Yosys for this lab. The path-group script is adapted from the ibex synthesis flow.
